# Contribuindo

Obrigado por considerar uma contribuição para este projeto.

## Como contribuir

1. Faça um fork do projeto.
2. Crie uma branch para sua feature ou correção:
   ```bash
   git checkout -b feature/minha-melhoria
   ```
3. Faça suas alterações com foco em qualidade e clareza.
4. Execute os testes locais:
   ```bash
   npm test
   ```
5. Abra um Pull Request com uma descrição objetiva do que foi alterado.

## Regras

- Mantenha a estrutura do código limpa e legível.
- Evite alterações fora do escopo da funcionalidade.
- Testes devem continuar passando.
- Documente mudanças relevantes.

## Feedback

Issues e sugestões são bem-vindas.
