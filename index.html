Sobre o projeto

Tecnologias

HTML5 semântico, CSS moderno com design tokens, Chart.js para visualização e JavaScript modular para lógica de estado e dados simulados.

Desafios resolvidos

Gerenciamento de filtros, carregamento assíncrono, exportação de dados e interação em múltiplos breakpoints, tudo mantendo a experiência visual refinada.

Aprendizado

Foquei em arquitetura de dados, acessibilidade, performance e uso de componentes reutilizáveis para criar uma solução de portfólio com narrativa forte.
